# 🐾 PAW MAP — v0.9.50 Secure Beta

SillyTavern RP의 장소, 이동, 이벤트, NPC를 지도와 약도로 정리하는 확장입니다. 지도 본체는 키가 필요 없는 공개 지도 소스를 사용하며, Google 지도 웹 링크는 기본 OFF인 선택 기능입니다.

## 이번 베타의 핵심

- Leaflet CDN/CARTO 래스터 지도 대신 로컬 번들 MapLibre GL + OpenFreeMap 벡터 지도를 사용합니다.
- 지도 엔진 코드와 CSS는 확장에 포함되어 있어 실행 중 외부 CDN에서 스크립트를 받지 않습니다.
- 하나의 지도 검색창에서 등록 장소를 먼저 찾고, 결과가 없을 때 Enter를 누르면 Photon/OpenStreetMap 주소 검색으로 이어집니다. 입력 중에는 외부로 보내지 않습니다.
- 자동 장소명 지오코딩은 기본 OFF이며, 사용자가 별도로 동의한 경우에만 동작합니다.
- 지도를 직접 꾹 눌러 새 장소를 등록하거나 핀을 직접 옮기면, 그 RP 좌표만 Photon에 보내 주소를 자동 입력합니다.
- Google Maps/Places/Routes API, Google Grounding, Vertex AI, 외부 생성 이미지 기능은 포함하지 않습니다.
- 장소 상세의 Google 지도·Google 길찾기·Street View 웹 링크는 설정에서 켰 때만 보입니다. API 키나 Google Cloud 과금 계정은 필요하지 않습니다.

## 장소 자동 등록과 오탐 방지

기본값은 PAW MAP의 핵심 기능인 자동 감지·등록입니다.

`채팅 장소 탐지 → 강화된 오탐 필터 → 자동 등록·이동`

- 시스템 문구·대명사·문장 조각·복합 사물 표현 등 강화된 필터에서 거부된 이름은 등록되지 않습니다.
- `Room`, `Bedroom`, `Kitchen`, `방`, `침실` 같은 단독 내부 장소는 현재 상위 장소가 있으면 하위 장소로 자동 등록됩니다. 상위 장소가 없으면 전 세계 주소 검색을 하지 않고 후보로 보류합니다.
- 정확한 좌표가 없는 새 장소는 현재 장소에 좌표가 있을 때 30~150m 반경에 `≈ 추정 핀`으로 자동 표시됩니다.
- 추정 핀은 외부 통신 없이 로컬에서 계산하며 실제 주소로 표시하지 않습니다. Street View 좌표로도 사용하지 않습니다.
- 주소 검색·지도 직접 배치·허용된 자동 지오코딩으로 실제 좌표가 생기면 추정 표시를 제거합니다.
- 설정에서 `후보함에서 확인`을 고르면 자동 등록 대신 `탐지 → 메모리 후보 → 사용자 승인` 방식으로 사용할 수 있습니다.
- 후보 근거 문구는 메모리에만 두며 채팅을 바꾸거나 새로고침하면 사라집니다. `계속 무시`를 선택한 정규화 장소명만 로컬 설정에 저장됩니다.
- 약도의 기본 간선은 실제 이동 기록만 표시합니다. 모든 좌표 쌍을 자동 연결하지 않습니다.
- 설정의 `의심 장소 점검`에서 이전 오탐을 직접 선택해 정리할 수 있습니다. 자동 삭제는 하지 않습니다.
- 같은 화면에서 예전 버전이 군집 배치한 핀을 골라 `좌표·주소`만 초기화할 수 있습니다. 장소·이벤트·이동과 약도 위치는 보존됩니다.

## RP 경로와 이벤트

- `RP 경로`는 등록된 출발 장소와 도착 장소 사이에 직선 경로, 직선거리, 예상 도보 시간을 표시합니다.
- 경로는 현재 지도 세션에만 남으며 DB, 이동 기록, 거리 관계에 자동 저장되지 않습니다. 외부 경로 API도 호출하지 않습니다.
- 추정 핀이 포함되면 `추정 좌표 기반`으로 표시됩니다. 실제 도로를 따라가는 턴바이턴 길찾기가 아닙니다.
- `Drift point` 등 감사·메타 로그는 이벤트 추출 전에 제외하며, 모바일 이벤트 카드는 한 번 누르면 펼쳐지고 다시 누르면 닫힙니다.

## 커뮤니티 생성 방식

- `기본 생성`: Google·Photon·Overpass를 호출하지 않고 저장된 RP 장소·이벤트·캐릭터 맥락으로 생성합니다.
- `주변 정보 보강 생성`: 확정 좌표를 반올림해 Overpass에 보내고 주변 POI를 받아 생성에 보강합니다. `≈ 추정 핀`에서는 사용하지 않습니다.
- 두 방식 모두 선택한 SillyTavern 연결 프로필의 AI를 사용합니다. PAW MAP이 별도 카드나 결제 계정을 연결하지 않으며, 해당 공급자 계정의 토큰·크레딧·사용량이 차감됩니다.

## 보안 기본값

업데이트 후 다음 기능은 강제로 OFF에서 시작합니다.

- 외부 AI 호출
- RP/채팅 원문을 생성 연결 프로필에 전달
- 이벤트·예정 일정 자동 AI 생성
- 드래그 AI 요약
- 감지된 장소명 자동 지오코딩
- 지도 맥락의 일반 채팅 프롬프트 주입
- 디버그 로그
- Google 지도·Google 길찾기·Street View 링크 표시
- 확장 자동 업데이트

확장은 API 키 입력란을 제공하지 않으며 API 키를 읽거나 저장하지 않습니다. 생성 기능은 사용자가 선택한 SillyTavern 연결 프로필 ID만 사용합니다. 실패 시 다른 프로필이나 공급자로 자동 재시도하지 않습니다.

연결 프로필로 보내는 임시 프롬프트와 선택형 일반 채팅 지도 맥락에서는 흔한 API 키, `client_secret`, AWS 비밀키, access/refresh/id token, Basic·Bearer 인증값, PEM 개인키 형태를 추가로 마스킹합니다. 최근 채팅의 system 메시지와 선택 프로필의 프리셋·지시문은 유틸리티 생성 요청에 덧붙이지 않습니다. IndexedDB에 저장된 RP 원문과 사용자가 직접 내려받는 백업은 이 과정에서 바꾸지 않습니다.

외부 AI 기능은 PAW MAP이 새 결제 계정이나 카드를 연결하는 방식이 아닙니다. 이미 선택한 SillyTavern 연결 프로필의 공급자 계정으로 요청하며, 그 계정의 토큰·크레딧·사용량이 차감됩니다. 실제 청구 방식은 기존 공급자 계정 설정을 따릅니다.

이전 버전에 저장된 직접 API 키 또는 서비스 계정 JSON은 시작할 때마다 확장 설정에서 삭제됩니다. 보안 베타 설치 전에도 SillyTavern 설정 백업을 별도로 보관하는 것을 권장합니다.

## 로컬에 저장되는 데이터

장소, 좌표, 주소, 이동, 이벤트, NPC, 커뮤니티/리뷰 생성 결과와 사용자가 추가한 사진은 브라우저의 IndexedDB에 저장됩니다. 사진은 압축된 데이터 URL 형태로 저장됩니다.

“전체 백업”으로 내려받는 JSON에는 이 데이터가 평문으로 포함됩니다. 백업 파일은 채팅 기록과 비슷한 민감도로 다루고, 공유 전 내용을 확인하세요.

장소 후보와 후보의 근거 문구는 백업에 포함되지 않습니다. 다만 승인한 장소와 `계속 무시` 목록은 로컬 데이터에 남습니다.

확장 코드는 프롬프트·채팅 원문·LLM 원문 응답을 콘솔에 출력하거나 진단 복사본에 포함하지 않습니다. 안전 진단 화면에는 상태 코드와 비밀이 아닌 설정만 표시됩니다.

## 설치

1. 이 폴더를 SillyTavern의 사용자 확장 폴더에 넣습니다.
2. SillyTavern을 다시 시작하거나 확장을 다시 로드합니다.
3. 확장 설정에서 PAW MAP을 엽니다.
4. 먼저 약도와 수동 주소 검색을 확인합니다.
5. 외부 AI 기능이 필요할 때만 연결 프로필을 선택하고, 외부 AI 및 RP 공유 동의를 각각 켭니다.

## 지도 데이터와 저작권 표시

현실 지도는 OpenFreeMap 스타일과 OpenStreetMap 데이터를 사용합니다. 지도 화면의 출처 표시는 제거하지 마세요.

- MapLibre GL JS 6.1.0: BSD-3-Clause, `vendor/maplibre/LICENSE.txt` 및 공급망 해시 `vendor/maplibre/SOURCE.md`
- OpenFreeMap: https://openfreemap.org/
- OpenStreetMap contributors: https://www.openstreetmap.org/copyright
- Photon: https://photon.komoot.io/
- Overpass API: https://wiki.openstreetmap.org/wiki/Overpass_API

## 알려진 한계

- Google 지도와 동일한 장소 DB, 리뷰, 영업시간, 교통량, 스트리트뷰는 제공하지 않습니다.
- Google 버튼은 Google 웹페이지를 새 탭으로 열 뿐, 결과를 PAW MAP으로 수집하거나 저장하지 않습니다.
- Google 링크 클릭 시 Google은 쿼리/RP 좌표와 IP·브라우저 정보, 로그인 상태에 따른 계정 활동을 처리할 수 있습니다.
- 내부 `RP 경로`는 직선 기반이며 실제 도로·교통·턴바이턴 안내를 제공하지 않습니다. 외부 Google 길찾기는 설정을 켰 때만 보입니다.
- PAW MAP은 실제 기기 위치를 Google URL에 넣지 않지만, 열린 Google 페이지가 위치를 사용하는지는 Google과 브라우저의 위치 권한 설정을 따릅니다.
- 공개 지도/검색 서비스의 정책이나 가용성이 바뀌면 엔드포인트 교체가 필요할 수 있습니다.
- 같은 SillyTavern 페이지에서 실행되는 다른 확장까지 격리하는 보안 경계는 아닙니다. 신뢰하지 않는 확장과 함께 사용하지 마세요.

## v0.9.47-secure-beta 변경 요약

- 새 장소·별칭·약속 장소를 후보함으로 강제하던 변경은 v0.9.49에서 철회
- 한 글자 부분 매칭, 문장 전체 이동어 연계, 복합 사물/행사 용례(`bar of soap`, `office chair`, `club sandwich`, `office party`) 방어
- `left Club`/`클럽에서 나왔다` 같은 출발지 표현을 목적지 이동으로 처리하지 않음
- 시스템 문구·대명사·문장 조각 하드 거부 및 일반 시설명 저신뢰 처리
- 기존 장소 자동 이동은 자동 모드의 강한 이름 인접 이동 표현만 허용
- 좌표 전체 쌍 자동 거리 생성은 중단하고, 좌표 불명 장소의 명시적 추정 핀만 v0.9.49에서 복구
- 약도 간선을 실제 이동 기록 중심으로 변경, 이전 자동 추정 거리 정리 도구 추가
- 검토식 의심 장소 정리 UI 추가
- 선택형 좌표·주소 초기화로 기존 군집 핀을 기록 손실 없이 재배치 가능
- 고정 Google Maps 웹 URL 빌더와 사용자 클릭형 보기/길찾기/Street View 추가
- Google 링크에 API 키·UTM·임의 호스트·실제 기기 출발지 대체를 허용하지 않음
- 백업 입출력에서 키·토큰·Authorization·client secret 이름의 필드를 중첩 위치와 관계없이 제거
